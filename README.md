# טבלה מחזורית כרשת

אותם 118 יסודות, בשבעה סידורים שונים. האפליקציה מראה קשרים שהטבלה הקלאסית מסתירה, ומשתמשת בהם כדי להציע השערות לחומרים חדשים.

## הסידורים
- **מטריצה**: הטבלה הקלאסית, צבועה לפי משפחה, גיאוכימיה או תכונה. בחירת יסוד מדליקה את השכנים שלו ברשת.
- **רשת**: יסודות כצמתים, מחוברים לפי דמיון. ארבע עדשות: היסטוריה כימית (תבניות תרכובות, בשיטה של Leal ואחרים, מקס פלאנק), התנהגות כימית, גודל ואנרגיה, וגיאוכימיה (Goldschmidt). הדף מציג גם את "הקשרים המפתיעים".
- **מחזוריות משנית**: קשרים אלכסוניים, מהלך פרש, n ו-n+10, וחריגות של השורה הרביעית והשישית.
- **ספירלה**: רצף אחד בסגנון Benfey.
- **מעבדת חומרים**: החלפת יסוד בתרכובת ידועה בשכן קרוב. ההחלפה מדורגת בשתי שכבות שקופות, היסטוריה ותכונות. השערות נשמרות עם הערות.
- **טבלת נתונים**: כל היסודות, ממוינים ומקובצים, עם קישור מכל תא.

האתר החי: https://anat1969.github.io/TavlaMachzorit-GH/

## הרצה
```
npm install
npm run dev            # פיתוח
npm run build          # dist/ לפריסה
npm run build:single   # dist-single/index.html: קובץ אחד עצמאי
npm run deploy         # פריסה ל-GitHub Pages (ענף gh-pages)
```

## מבנה
- `src/data/`: יסודות (מקור אחד לכל התכונות), תרכובות, קשרי מחזוריות משנית
- `src/lib/`: חישובי דמיון ועדשות (`similarity.ts`), החלפות (`substitute.ts`), ניתוב, צבעים, שמירה
- `src/components/`: גריד מחזורי לשימוש חוזר, כרטיס יסוד, מקרא, צ'יפים
- `src/pages/`: דף לכל סידור
- `src/index.css`: מערכת העיצוב. כל הצבעים מוגדרים כאסימונים במקום אחד

## החלטות
- המאגר הוא מדגם של כ-670 תרכובות בינאריות מוכרות, ולא אלפי התרכובות של המחקר המקורי. הרשת מדגימה את השיטה, והממשק אומר זאת במפורש.
- התווית "השערה" אומרת רק שהנוסחה לא נמצאת במדגם. היא לא אומרת שום דבר על יציבות.
- השערות והערות נשמרות ב-localStorage, עם חיווי בכל שמירה ובכל שגיאה.
